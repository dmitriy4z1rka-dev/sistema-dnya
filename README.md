# Моя система дня

Персональный ежедневник в одном HTML-файле: план 1–3–5, недельное расписание тайм-блоками, привычки, канбан проектов, недельный ревью и статистика.

Работает офлайн, без регистрации. Данные хранятся в браузере (localStorage) на каждом устройстве отдельно; перенос — через «Настройки → Экспорт / Импорт JSON».
